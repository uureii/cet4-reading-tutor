# 长难句拆解方法论

Step 3 长难句专项、以及第 ④ 段结构分析遇到从句 / 非谓语 / 倒装时使用。**按本文件的步骤讲，不要临场发明术语。**

---

## 一、三步断句法（所有长句通用）

```
Step 1  数谓语  → 有几个"真正的谓语动词"，就有几个分句
Step 2  找边界  → 用连接词 / 关系词 / 非谓语 / 标点，把每个分句圈出来
Step 3  先剥后挂 → 剥掉全部修饰，只译主干；再把修饰一层层挂回去
```

**谓语识别要点**：

- 一个句子只有一个主句谓语（并列谓语除外，用 and/but/or 连接）
- 前面有 `to` 的是不定式，不是谓语
- 前面有 `having been / being` 的是非谓语
- 跟着关系词 `that / which / who` 且后面还有自己主语的，是另一个分句的谓语

**翻译顺序**：不要从第一个词开始顺着译。先把主干译成一句短中文，再处理修饰，最后调整语序。

---

## 二、五大基本句型（判断主干用）

| 句型 | 结构 | 判别方法 | 例 |
|---|---|---|---|
| 主谓 | S + V | 后面没有宾语也能成立 | Prices **rose**. |
| 主谓宾 | S + V + O | 动词是及物动词，缺宾语不成立 | The study **found** a link. |
| 主系表 | S + V + P | 动词是 be / become / seem / remain / prove / appear | The result **seems** surprising. |
| 主谓双宾 | S + V + O1 + O2 | 动词是 give / offer / tell / show / award | They **gave** us two options. |
| 主谓宾补 | S + V + O + C | 宾语和补语之间有"是"或"成为"关系 | They **consider** it a success. |

判别口诀：**先找谓语动词，再问"它后面缺什么"**。缺宾语 → 主谓宾；缺表语（描述主语）→ 主系表；缺补语（描述宾语）→ 主谓宾补。

---

## 三、从句三步定位

**第一步：看连接词**

| 类型 | 标志词 | 在句中的角色 |
|---|---|---|
| 名词性从句 | that / whether / if / what / who / how / why / because | 当主语、宾语、表语、同位语（**不能删，删了句子不完整**） |
| 定语从句 | who / whom / whose / which / that / when / where / why / as | 修饰前面的名词（**删了句子仍完整**） |
| 状语从句 | when / while / because / although / if / unless / so that / whereas | 修饰整个主句（**可前可后，位置灵活**） |

**第二步：做删除测试**

去掉从句后主句还成立 → 定语或状语从句；主句塌了 → 名词性从句。

**第三步：看修饰对象**

从句前面紧挨着名词，且从句内部缺主语或宾语 → 定语从句，修饰那个名词。
从句内部完整，且位置可在句末也可提到句首 → 状语从句。

### 定语从句三个高频难点

| 难点 | 表现 | 讲法 |
|---|---|---|
| 关系代词省略 | `the method (that) researchers used` | 告诉学习者：`used` 前面其实藏了个 that，先把它补回去再读 |
| 介词 + which | `the extent to which...`、`the degree to which` | 整条当作"在多大程度上"来记，不要拆 |
| 非限制性从句 | `, which means...` | 逗号 + which 修饰的不是某个词，而是前面整句话；译成"这就意味着…" |

## 四、非谓语三选一（-ing / -ed / to do）

判断只需两问：

```
问1：它跟逻辑主语是主动还是被动？
     主动 → -ing        被动 → -ed
问2：动作和谓语谁先谁后？
     之后 / 目的 → to do      同时 → -ing      之前 → having done / -ed
```

常见固定角色：

- 句首 `-ing` 短语 + 逗号 → 多数是状语（表原因、条件、伴随），逻辑主语 = 主句主语
- 名词后 `-ing` / `-ed` 短语 → 后置定语，等价于一个定语从句
- `to do` 在句末 → 目的状语最多
- `-ed` 开头 → 被动或完成，先译成"被…"或"在…之后"

**易错点**：句首 `-ing` 的主语必须是主句主语，若不是，原文就是悬垂结构（dangling modifier），照实说明，不要强行解释通。

## 五、插入语与同位语（读不下去的元凶）

| 形式 | 识别特征 | 处理方式 |
|---|---|---|
| 逗号成对插入 | `, however,` / `, by contrast,` / `, in other words,` | 直接跳读，不参与主干 |
| 破折号插入 | `— a point few dispute —` | 整段括起来，读完主干再回头看 |
| 括号 | `(see Figure 2)` | 一律最后看 |
| 同位语 | 名词 + 逗号 + 名词 / `the fact that...` | 后者在解释前者，译成"即…"或"…这一事实" |
| 长主语后置 | `It is + adj + that...` | 形式主语 it，真正内容在 that 从句里 |

**教学要求**：遇到插入语，必须明确告诉学习者"从这里到那里可以整段先跳过"，这是最实用的一条阅读技巧。

## 六、倒装与强调（还原成正常语序再讲）

| 类型 | 例句 | 还原 |
|---|---|---|
| 否定词置首 | `Not only did costs fall, but quality improved.` | costs not only fell... |
| Only + 状语置首 | `Only then did researchers notice...` | researchers noticed only then |
| so / such 置首 | `So common is the belief that...` | The belief is so common that... |
| 虚拟省略 if | `Were the trend to continue, ...` / `Had it not been for...` | If the trend were to continue... |
| 表语 / 状语前置 | `Among the findings is a striking one.` | A striking finding is among them. |
| 强调句 | `It was the cost, not the benefit, that changed their minds.` | 强调 cost |

讲倒装时**先还原、再翻译**，不要让人硬啃倒装语序。

---

## 七、省略与替代

| 现象 | 标志 | 讲法 |
|---|---|---|
| 定语从句省略宾语关系词 | `the data (that) they collected` | 补 that |
| 状语从句省略主语 + be | `while (they were) under pressure` | 补回去 |
| 并列结构省略 | `Some support it; others (support) the opposite.` | 指出省略位置，避免误读为不同动词 |
| 比较句省略 | `than previously thought` | 补 `than it was previously thought` |
| 替代词 | `one / ones / that / those / it / do so / so` | **必须指出回指对象**，这是四级阅读最常设错的考点 |

**替代词回指**是重点，每遇到一次都要明确指出指谁：`those of developing countries` 中的 those = the economies（举例）。

## 八、比较结构（译错就整句翻车）

| 结构 | 正确译法 |
|---|---|
| not so much A as B | 与其说 A，不如说 B |
| more A than B | 与其说 B，不如说 A（强调 A） |
| no more than + 数字 | 只不过、仅仅 |
| not more than + 数字 | 不超过 |
| A is to B what C is to D | A 之于 B，如同 C 之于 D |
| rather than | 而不是（前后要对称） |
| as ... as any | 不亚于任何 |
| the more ..., the more ... | 越…越… |

## 九、名词化还原（学术文章最常见的"读不懂"）

英文爱把动作写成名词，中文爱用动词。遇到 `the + 抽象名词 + of` 先还原成小句：

| 原文 | 还原 | 译文 |
|---|---|---|
| The rapid expansion of the city led to a shortage of housing. | The city expanded rapidly, so housing became short. | 城市扩张过快，导致住房短缺。 |
| Their refusal to accept the evidence weakened the argument. | They refused to accept the evidence, which weakened the argument. | 他们拒绝接受这些证据，这让论点站不住脚。 |
| A lack of sleep impairs the consolidation of memory. | When people lack sleep, memory consolidates poorly. | 睡眠不足会影响记忆的巩固。 |

**讲法**：先还原成"谁做了什么"，再译。不要在名词堆里硬拼中文。

## 十、中文译序四步法（第 ④ 段"译序"栏专用）

```
1. 切   按连接词 / 介词短语 / 非谓语 / 标点切成意群
2. 定   定主干（谁 + 做了什么 + 对象）
3. 挂   把每个修饰挂到它修饰的成分上
4. 排   按中文习惯重排：
        · 状语（时间、地点、原因、条件）往前挪
        · 短定语放名词前，长定语拆成独立小句
        · 被动句无必要时改主动，或加"人们 / 研究者"作主语
        · 英文后置的补充说明，中文可提到前面，也可另起一句用"这"
```

每一步只需一两句话说明**为什么这么排**，不要写成语法讲义。

## 十一、五个可套用的长句骨架

遇到就读出骨架，直接套讲法：

| 骨架 | 例句形态 | 讲法 |
|---|---|---|
| 主语从句 + be + 表语从句 | `What matters is whether...` | 前半整体是主语，别拆；译成"关键在于…是否…" |
| 名词 + 定语从句 + 主句谓语被推远 | `The idea that X, which Y, has...` | 先把主句谓语找出来，中间全是修饰 |
| It 形式主语 + that 真主语 | `It is widely assumed that...` | 译成"人们普遍认为…"，不要"它是被广泛假设的" |
| 让步 + 转折 | `Although A, B.` / `A, yet B.` | 中文习惯"虽然…但是…"，保留让步在前 |
| 结论前置 + 解释后置 | `The effect was limited: only X showed...` | 冒号后是解释，译时可加"即"或"因为" |

---

## 十二、讲解自检

讲完一句长难句，学习者应该能回答这四个问题：

1. 这句话的主语是哪个词？
2. 谓语是哪个词？
3. 哪一段可以整段先跳过？
4. 中文为什么把 X 放到了 Y 前面？

四个都答不上，就是没讲透。
