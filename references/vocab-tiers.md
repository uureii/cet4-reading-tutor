# 生词筛选口径（四级考纲基准）

标注太多等于没标；标注太少等于白读。本文件给出可执行的判断流程，避免"凭感觉挑词"。

---

## 一、基准线

以**高考英语 110–120 分学生的已知词汇量（约 3000 词）为下限基准**。

- 低于这条线的词（the / important / because / people）一律不标，除非它在句中是熟词僻义
- 四级考纲约 4500 词；其中真正需要"提醒"的是核心高频 + 熟词僻义 + 固定搭配
- 一条实用判据：**"一个高考 115 分的大一学生，看到这个词会不会卡住 2 秒以上？"** 会 → 标；不会 → 跳过

---

## 二、判断流程（按顺序走，命中即停）

```
1. 是专有名词 / 机构名 / 人名地名？
   → 不放进生词表。若构成理解障碍，在 ⑤背景 里一句话交代即可。

2. 是四级考纲内 + 本句用的是常用义？
   → 不标。

3. 是四级考纲内 + 本句取的是生僻义项？
   → 标，级别写「熟词僻义」，并在"本句义"里明确"此处不是 XX 义"。

4. 是考纲内的词，但构成固定搭配 / 短语动词，且整体义 ≠ 字面义？
   → 标，级别写「陷阱词」，整条短语一起列（不要拆成单词）。

5. 是考纲外，且属六级 / 考研常见词？
   → 标，级别写「超纲 ⚠️」，并加一句"认识即可，不要求拼写"。

6. 是考纲外的专业术语，或全篇只出现一次？
   → 标，但注明「认识即可」，不进入必背清单。

7. 以上都不是 → 不标，本句写"生词：无"。
```

## 三、必标清单（看到就标）

| 类别 | 例子 | 为什么必须标 |
|---|---|---|
| 熟词僻义 | `address the issue`（处理，非"地址"） | 认识字面义反而会译错 |
| 短语动词 | `account for`（占…比例／解释） | 拆开看完全猜不到 |
| 逻辑连接词 | `whereas`、`albeit`、`notwithstanding` | 读不懂就抓不住论证方向 |
| 态度形容词 | `skeptical`、`ambivalent`、`compelling` | 直接决定主旨题答对与否 |
| 抽象名词化 | `the implementation of`、`a tendency toward` | 中文没有对应结构，读起来最卡 |
| 学术动词 | `indicate`、`suggest`、`attribute`、`yield` | 四级高频且易混 |

## 四、不要标清单（看到就跳过）

- 基础功能词：the / of / which / because / however（`however` 只在表示"无论如何"时标）
- 高频常识词：important / problem / study / result / increase / people
- 数字、日期、百分比
- 人名、地名、机构缩写（NASA、WHO）
- 已在块内前一句标过的词（同块内不重复标，跨块可重复一次）

## 六、四级核心高频（值得主动标注并背诵）

按功能分组，每组挑 1–2 个标即可，不必全标。

**学术论证**
indicate / suggest / demonstrate / reveal / confirm / propose / argue / claim / imply / assume / attribute A to B / account for / give rise to / result from / stem from / be consistent with / contradict

**研究描述**
hypothesis / variable / sample / participant / finding / evidence / data / survey / trial / mechanism / correlation / tendency / phenomenon（复 phenomena）/ pattern

**程度与评价**
considerable / substantial / dramatic / moderate / slight / subtle / valid / reliable / convincing / compelling / questionable / controversial / ambiguous / inevitable

**态度与立场**
skeptical / critical / optimistic / pessimistic / objective / neutral / indifferent / cautious / supportive / doubtful

**逻辑连接（决定论证方向，必标）**
whereas / nevertheless / nonetheless / conversely / by contrast / on the contrary / in turn / thereby / hence / accordingly / moreover / in addition / provided that / unless / albeit / notwithstanding / rather than / as opposed to

**抽象名词化（中文最难处理）**
the implementation of / the emergence of / a shift in / the decline in / the tendency to / a lack of / the extent to which / the assumption that

## 七、超纲判定

考纲外但值得一眼认出的词，特征通常是：

- 拉丁/希腊词根 + 学术词缀：`proliferation`、`discrepancy`、`prevalence`、`attributable`
- 六级/考研高频：`alleviate`、`deteriorate`、`predominantly`、`underlying`、`inherent`
- 学科术语：`cognitive`、`metabolism`、`inflationary`

处理方式统一：标 ⚠️ + 一句话释义 + "认识即可"。**不进入必背清单，不在自测题里考拼写。**

---

## 八、数量自检

一篇 300 词的文章，生词表控制在 **15–25 条**：

- 少于 10 条：可能漏标，回头看有没有熟词僻义和短语动词被放过
- 多于 30 条：筛选失效，学习者只会放弃背诵

必背与认识即可的比例大致 6:4。
